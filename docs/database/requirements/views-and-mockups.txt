============================================================
PALETA GENERAL SUGERIDA
============================================================

Objetivo visual: moderno, limpio, legible en operación, con estados rápidos de reconocer.

Paleta base:
- Fondo principal oscuro: RGB(18, 18, 20)
- Fondo secundario/tarjetas: RGB(30, 30, 34)
- Superficie elevada: RGB(42, 42, 48)
- Texto principal: RGB(245, 245, 245)
- Texto secundario: RGB(180, 180, 190)

Acentos:
- Primario / acción: RGB(232, 89, 48)
- Secundario / información: RGB(53, 132, 228)
- Éxito / disponible: RGB(46, 160, 90)
- Advertencia / baja disponibilidad: RGB(235, 177, 52)
- Error / agotado / anulado: RGB(210, 65, 65)
- Neutral / deshabilitado: RGB(105, 105, 115)

Uso recomendado:
- Verde: disponible, pagado, listo, confirmado.
- Amarillo: baja disponibilidad, espera, atención necesaria.
- Rojo: anulado, suspendido, error, agotado.
- Azul: información, comunicación, estados de proceso.
- Naranja/rojo cálido: botones principales, marca, acciones rápidas.

Evitar:
- usar rojo como botón primario normal;
- depender solo del color para transmitir estado;
- demasiados colores saturados en cocina/KDS.

Acceso de clientes. Todo nuevo registro público recibe automáticamente rol Cliente.

Elementos:
- Logo/nombre
- Correo o teléfono
- Contraseña
- Iniciar sesión
- Crear cuenta
- Recuperar acceso
- Aviso de privacidad
